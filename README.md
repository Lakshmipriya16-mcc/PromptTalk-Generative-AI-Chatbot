

## 📌 Project Overview

PromptTalk is an AI-powered chatbot that generates responses to user prompts using a language model.
This project demonstrates how generative AI can be integrated into Python applications.

# PromptTalk – Generative AI Chatbot

PromptTalk is a Generative AI chatbot built using Python and Jupyter Notebook. 
It accepts user prompts and generates intelligent responses using an AI model.

## 🚀 Features
- Interactive chatbot
- Generative AI responses
- Easy to run in Jupyter Notebook

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- OpenAI API (or Hugging Face)

## 📂 Project Structure
PromptTalk-Generative-AI-Chatbot/
├── notebooks/
│   └── PromptTalk.ipynb
├── requirements.txt
├── README.md
└── .gitignore

## How to Run

1. Install dependencies:
   pip install -r requirements.txt
2. Open Jupyter Notebook
3. Run PromptTalk.ipynb
